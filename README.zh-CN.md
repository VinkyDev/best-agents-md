## 简介

best-agents-md 是一份放进 `AGENTS.md` 的简短代码规范，让 Agent 写出的代码更少、更干净、测试更有价值。包含代码规范、测试标准和 Bug 修复流程，适用于任何编程语言，以及任何读取 `AGENTS.md` 的 Agent（Codex、Claude Code 等）。

我们致力于成为最短但能发挥最大作用的代码开发提示词，并跟着模型更新和社区反馈不断进化，确保符合最新的最佳实践。

## 使用

在项目目录中运行（需要 Node.js 18 或更高版本）：

```sh
npx best-agents-md
```

它会把规范以带标记的区块写入 `AGENTS.md`，不改动文件中的其他内容。再次运行即可更新到最新版本。

也可以手动将 [AGENTS.md](AGENTS.md) 复制到你的项目中。
